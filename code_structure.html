Sequence of Agent & Tool Loop

Step-by-step sequence diagram illustrating how tool invocation loops re-prompt the LLM until completion. 

                    sequenceDiagram
                        autonumber
                        actor User
                        participant Loop as Agent Loop
                        participant Parser as Tool Parser
                        participant LLM as Gemini API
                        participant Tool as Tool Registry

                        User->>Loop: Enter prompt (e.g., "Fix test_calc.py")
                        Loop->>LLM: execute_llm_call(conversation)
                        LLM-->>Loop: Response text (e.g. "tool: read_file({...})")
                        Loop->>Parser: extract_tool_invocations(text)
                        Parser-->>Loop: Returns [("read_file", args)]
                        
                        alt Tool Call Detected
                            Loop->>Tool: Execute read_file_tool(args)
                            Tool-->>Loop: Return {file_path, content}
                            Loop->>Loop: Append "tool_result(...)" to conversation
                            Loop->>LLM: execute_llm_call(updated_conversation)
                            LLM-->>Loop: Response text (Final answer)
                        end

                        Loop->>User: Display final response

🛠️
Registered File Manipulation Tools
  • read_file_tool(filename) Lines 35 – 48

    Resolves file paths relative to current working directory and returns full file content.

  • list_files_tool(path) Lines 50 – 66

    Scans a directory using Path.iterdir() and classifies entries as files or directories.

  • edit_file_tool(path, old_str, new_str) Lines 68 – 95

    Performs exact string replacements or creates new files if old_str is empty.
